verify_relative uses fixed, vetted wording (no model call) so the confirmation request is predictable:
- To the relative's saved number: "{app_name}: <Person> got a message from someone saying they're you. Was it really you? Reply YES if it was you, or NO if it wasn't."
- To the person: "I've texted <Relative> on their saved number to check. Don't send anything or share any codes until they answer."
- If the claim came from the relative's own number: tell the person to call the relative directly on the number they
  know and ask for the family code word (never include the code word), and ask another family member to check.
